# Exercise 3: System design (25 min)

> Trades arrive through Solace, are processed by Java services, stored in MongoDB and submitted to a regulator through an S3 reporting file. The file must be delivered by 07:00 UTC on T+1.
>
> Design a solution that can survive infrastructure failures and still meet the deadline.

- 15 min: design and explain your solution. Draw if it helps.
- 10 min: discussion of production incidents and leadership.
